== 描述 ==

CPT UI 为您的 WordPress 网站带来完整的功能集合。轻量、定期更新，
兼容所有现代主题与页面构建器。

== 安装 ==

1. 在管理面板中进入 插件 -> 安装插件，点击 上传插件。
2. 选择 cpt-ui.zip 文件，点击 现在安装。
3. 点击 启用。
